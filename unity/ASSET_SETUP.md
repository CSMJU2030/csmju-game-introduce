# Local licensed artwork

Modern Interiors prohibits distributing its artwork to others. Its PNG files and the user-supplied Fantasy Battlers demon PNG are excluded from this repository. Tile definitions, scenes and importer `.meta` files remain tracked so authorized users can restore the original files without changing their GUIDs.

The original complete working project on Jimmy's machine is:

`/Users/jimmy/csmju-game-demo/csmju-digital-campus-adventure`

Before opening or building this checkout, an authorized asset owner must copy the PNG files from these original project folders to the same paths under this checkout's `unity/` directory:

- `Assets/Art/ModernCampus/`
- `Assets/Resources/Battle/bug.png`

Preserve the tracked `.meta` files. Obtain your own applicable asset licenses before sharing or distributing artwork. The checkout alone does not contain the complete licensed visuals required by the current game.
