# Third-party assets and attribution

- **Mana Seed Character Base Demo 2.0** by Seliel the Shaper. The source PNG sheets are from the user-provided/local free demo pack; four layers are composited into a 24-frame directional walking sheet for the game. Source: [itch.io asset page](https://seliel-the-shaper.itch.io/character-base). The original readme is kept at `Assets/Resources/Characters/ManaSeed/ORIGINAL_README.txt`. Follow the license/terms bundled with the original download for redistribution and commercial use; this project does not claim ownership of the character art.
- **IBM Plex Sans Thai** by IBM, included as Regular and SemiBold. License notice: `Assets/Resources/Fonts/OFL.txt`. Typeface source: [IBM Plex](https://github.com/IBM/plex).
- **Cute Fantasy RPG (Free)** by Kenmi: https://kenmi-art.itch.io/cute-fantasy-rpg. Earlier versions used four idle animation frames from `Enemies/Slime_Green.png` as Bug; the current battle uses the user-provided Fantasy Battlers demon. The legacy sprites remain in the project for reproducibility. The older five maps use its grass, path, water, farmland, tree, house and decoration sprites. Free version is licensed for non-commercial projects; modification is permitted and standalone redistribution/resale is prohibited. Original notice retained at `ArtSources/Kenmi/read_me.txt`. Credit is displayed on the game title screen. `Tools/make_assets.py` composes the map layouts from these licensed assets.

WebGL packaging compresses engine output with gzip. The generated WebGL build is an output artifact; retain notices above when sharing the source project.

## Modern campus expansion
Modern Interiors by LimeZu, from the user-provided Modern_Interiors_RPG_Maker_Version.zip. Character sheets (XP layout within the same package), classroom furniture, and floor tiles are used in-game. Required credit appears on the title screen. The original license is retained at Assets/Art/ModernCampus/LICENSE-Modern-Interiors.txt. Only selected sprites are imported; original archives are not distributed.

Fantasy Battlers - Complete, user-provided archive: battler 28 (winged demon) replaces the slime. The supplied PNG is static; lunge, recoil, tint and projectile animation are provided by the game. Fungus Cave archive was inspected but is not needed for this campus update.

- **Prompt** by Cadson Demak, distributed under SIL Open Font License 1.1. Used for game UI, NPC labels and the web shell. License: `Assets/Resources/Fonts/Prompt-OFL.txt`. Source: https://github.com/google/fonts/tree/main/ofl/prompt.
