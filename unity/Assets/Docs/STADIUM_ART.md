# Sports stadium artwork

Asset: `Assets/Art/Campus/campus-stadium.png`. Created with the built-in imagegen tool; no CLI fallback used. References: existing `campus-map.png` for pixel-art style; the stadium photograph supplied by the user for architecture. Only the generated stadium is included in the repository.

## Final generation prompt

Use case: stylized-concept. Asset type: opaque rectangular outdoor stadium patch for a top-down 2D pixel RPG campus map. Input image 1 (campus-map.png) is a STYLE reference only. Input image 2 (stadium photograph) is an architecture/content reference only. Generate a NEW standalone rectangular stadium map asset, landscape aspect ratio about 1.2:1. Match campus reference dense colorful detailed pixel art, orthographic bird's-eye RPG camera with slight visible front faces of objects, crisp pixel edges, sunny tropical Thai campus. In the northern TOP quarter put a covered grandstand with dark grey angular metal roof, grey bleacher seats and concrete stair access, inspired by photograph. Main playable area fills lower 70%: large green football pitch with white centre line, centre circle and penalty-box markings, two goals left/right; surrounded by oval red running track with thin white lane lines. Outer oval centred at x=0.54,y=0.60 of image, outer radii x=.40,y=.31. The west LEFT edge has a broad tan paved entrance walkway open from the map's left edge between 30% and 70% of image height, joining running track without walls or bushes blocking it. Flat tan concourse separates north grandstand and track. At outer north-west/north-east and south-west/south-east corners put four slim grey floodlight poles. Grass, modest low shrub borders and perimeter fence only along the far outer TOP, RIGHT, BOTTOM edges. Do NOT fence across western entrance. Fit the entire stadium into image; little margin. No people, no NPCs, no UI, no labels, no sky, no building elsewhere, no old stage or flowerbed. Background fully opaque, no transparency. This is a playable map texture; keep grass pitch, red track and west walkway visually clear and open.

## Integration

The stadium is a separate sprite overlay in the southeast corner, preserving the rest of the campus map. Its final track has rounded corners and straight sides; collision follows that generated shape rather than the prompt's ellipse. A tiled paving connection links the west gate to the campus paths. The same normalized coordinates are used for ground navigation and the mini map.
